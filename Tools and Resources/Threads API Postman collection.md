# Threads API Postman collection



[Postman](https://www.postman.com/) is a popular tool to help test and develop APIs. The Threads API Postman collection contains a full set of API calls to help you integrate with the Threads API.

This document shows you how to set up the Threads API Postman collection and use Postman to make requests to the Threads API.

## Threads API collection

The Threads API collection is available on Postman at [https://www.postman.com/meta/threads/overview](https://www.postman.com/meta/threads/overview).

The collection's Postman documentation covers the following:

* Authorization
* Post to Threads
* Read and Manage Threads
* Discover Threads
* Display Threads
* Troubleshooting

Instructions on how to set up the collection and use it to make requests are available in the [Get Started](https://www.postman.com/meta/threads/collection/dht3nzz/threads-api) section.

**Warning:** The Postman collection is updated over time, but it might not include all of the latest features. Please refer to the developer documentation changelog for the most up-to-date features: [Threads changelog](https://developers.facebook.com/documentation/threads/changelog).
